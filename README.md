# Робо-бой: Telegram Mini App

Автор идеи: PARADISSEDEMON
Реализация: CLAUDE AI

Вся игра помещается в один файл `index.html`. Сервер и база данных не нужны. Достаточно бесплатного хостинга с адресом `https://`.

## Что работает в Telegram

- Игра открывается на весь экран, сенсорные кнопки появляются сами.
- Прогресс хранится в облаке Telegram и переносится между телефоном и компьютером.
- Кнопка «Назад» Telegram: в бою ставит паузу, в меню возвращает в ангар.
- Удары, нокауты и победы отдаются вибрацией.
- Внизу ангара показан ник игрока.

## Запуск за 3 шага

### 1. Выложить игру (GitHub Pages, бесплатно)
1. Зарегистрируйся на github.com и создай публичный репозиторий, например `robo-boy`.
2. Нажми **Add file → Upload files** и загрузи `index.html`.
3. Открой **Settings → Pages**. В поле Source выбери `Deploy from a branch`, ветку `main`, папку `/ (root)` и нажми Save.
4. Через минуту появится адрес вида `https://твой-ник.github.io/robo-boy/`. Открой его в браузере и убедись, что игра запускается.

Подойдёт и любой другой хостинг с HTTPS: Netlify, Vercel, Cloudflare Pages.

### 2. Создать бота
1. Напиши [@BotFather](https://t.me/BotFather) команду `/newbot`, задай имя и username.
2. Кнопка «Играть» в чате: `/mybots` → твой бот → **Bot Settings → Menu Button** → Configure. Вставь адрес игры из шага 1 и подпись `Играть`.

### 3. Прямая ссылка на игру (по желанию)
В @BotFather выполни `/newapp`, выбери бота, укажи адрес игры и короткое имя, например `game`. Получишь ссылку `t.me/твой_бот/game`. По ней игра открывается сразу, без чата с ботом. Её удобно раздавать друзьям.

Описание бота, которое видно до нажатия Start, задаётся в @BotFather командой `/setdescription`. Например:
«РОБО-БОЙ: собери робота из деталей, прокачай его и выиграй четыре турнира. Автор идеи: PARADISSEDEMON. Реализация: CLAUDE AI».

## Обновить игру

Загрузи новый `index.html` в тот же репозиторий поверх старого. Через минуту-две у всех игроков откроется новая версия. Сохранения игроков не сбросятся.

## Проверка без Telegram

`index.html` можно открыть прямо в браузере. Игра запустится как обычная веб-версия с сохранением в браузере.
